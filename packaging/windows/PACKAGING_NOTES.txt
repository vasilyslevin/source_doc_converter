Source Document Converter - unsigned development build

This folder is not a production release. Keep the folder contents together.

Executables:
- SourceDocumentConverter.exe starts the desktop application.
- docling-tools.exe is the companion used only for explicit model setup.
- ocrmypdf.exe is the companion used to create searchable PDF output.

Models are not included. Choose a model folder and approve the download through Help > System Check. Document conversion does not automatically download models.

OCRmyPDF and a pinned UB-Mannheim Tesseract runtime are bundled in this Full development build.
Ghostscript is optional/recommended for PDF/A and advanced OCRmyPDF post-processing features.
If Ghostscript is missing, open Help > System Check for safe manual installation guidance.

Verify generated Markdown and JSON against the original PDF before relying on them. The original PDF remains authoritative.
